# saytimiz.uz

Платформа сверхбыстрых сайтов-визиток и персональных поддоменов для бизнеса в Узбекистане.

## Особенности проекта
- **Стек:** React 19, TypeScript, Vite, Tailwind CSS v4, `@phosphor-icons/react`, `motion`.
- **Эстетика (Taste Skill):** Строгий тёмный дизайн уровня Vercel/Linear (Zinc-950 + Emerald акцент + типографика Geist), адаптированный под рынок Узбекистана.
- **Интерактивный симулятор поддоменов:** ввод любого имени бизнеса (`zamondosh`, `fastfood`, `safia`) с моментальным предпросмотром мобильной визитки, скорости 0.18s, QR-кода и отправки заказа в Telegram.
- **Двуязычность:** мгновенный переключатель языка (O'zbekcha / Русский).
- **Прямая конверсия в Telegram:** заявки и бронирования формируют структурированное сообщение для Telegram-менеджера.
- **Готовность к Vercel:** конфиг `vercel.json` настроен.

## Запуск локально
```bash
cd saytimiz
npm run dev
```

## Сборка
```bash
npm run build
```
